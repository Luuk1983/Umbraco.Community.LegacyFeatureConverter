Choose how the converter should discover what to update.

Fast Fastest

Scans document types for properties using the legacy editor. Updates all matching document types, their data types, and all associated content. Document types with no content are also updated.

  • Fast — no extra content value scanning required.
  • Does not catch document types already updated by uSync whose content was never migrated.

Reasons from the macro registry. Converts every selected macro (creating element types, configuring macro-enabled Rich Text data types, writing stub partial views) and rewrites every content node that references those macros.

  • Fast and predictable — only walks content for macros currently in the registry.
  • Does not catch leftover macro markup whose IMacro was removed after a previous conversion. Reports any orphans in the log so you know to run Thorough if needed.
Thorough Slower

Everything the Fast approach does, plus a direct scan of content values to find any unconverted data. Catches the uSync scenario and recovers from partial migration failures.

  • Finds unconverted content even when the document type schema was already updated.
  • Safe to run after a partial or failed migration to ensure nothing was missed.
  • Slower: scans actual content values in addition to the schema.

Everything the Fast approach does, plus a recovery pass over orphan macro markup. For aliases whose IMacro was removed after a prior conversion, the converter looks for an existing element type with a matching alias and rewrites the orphan markup against it. Aliases with no matching element type are logged as warnings.

  • Recovers content where the IMacro definition was cleaned up but the element type is still in place.
  • Safe to run after a partial or failed earlier conversion.
  • Slower: scans every content node with macro-enabled Rich Text properties for orphan markup.
